# Historical Project Material

This directory preserves earlier specifications, prototypes, notes, and explorations. It documents how the project developed and can be useful when tracing a decision or an old issue.

It is not the current product documentation. In particular, several archived documents describe a Step 4 **Wikidata Designer**. The implemented workflow is now:

`Input -> Mapping -> Reconciliation -> References -> Export`

For current guidance, use [`../documentation/`](../documentation/README.md).
